Entry for the make.fun bounty **"The GPS Swears It Was a Shortcut"** — the GPS's
own one-line excuse for sending the driver down the wrong road.

## The line

> The school zone said twenty, the map said shortcut — I measure distance, not speed limits, and the map has never once been pulled over.

135 characters, one line, no setup, no dialogue tag — just the excuse, in the
GPS's own smug, defensive voice, blaming the map.

## How it works

`main.py` (Python 3.13, standard library only) validates the line against the
bounty gate — plain UTF-8 text, 1–200 characters, a single line — and writes
it, with no trailing newline, to `/output/entry.txt`.

```sh
python3 main.py
```
